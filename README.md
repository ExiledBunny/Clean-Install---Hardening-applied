Pre-entrega 2 - Rodrigo Artelino

Mi primer laboratorio seguro de ciberseguridad

Objetivo

Documentar la configuración de un laboratorio virtual de prácticas de ciberseguridad.

Actividades realizadas

Configuración de red de la máquina virtual en VirtualBox.

Creación de un usuario estándar en Windows.

Verificación de actualizaciones de Windows.

Inspección de permisos de archivos en Linux mediante ls -l.

Actualización de índices de paquetes con sudo apt update.

Creación de una instantánea inicial en VirtualBox.

Archivos del proyecto

reporte-tecnico.pdf: informe técnico con descripciones, evidencias y justificaciones.

evidencias: capturas de pantalla de las configuraciones realizadas.
